# v1.8 운영 밸런스 다듬기: 설계 (짧은 설계)

- 날짜: 2026-11-27
- 상태: 사용자가 "진행"으로 로드맵 v1.8과 문구 3곳을 승인함. 문구는 로드맵 초안의 문장을 그대로 쓴다.
- 로드맵: `2026-11-26-roadmap-draft.md`의 v1.8

모든 수치는 가상 값이다.

## 의도

v1.6에서 실제 휴식을 넣고 기준을 다시 정한 뒤 두 가지가 어긋났다.

1. **확장했을 때 이득이 반반에 가깝다.** 서비스를 지키며 확장한 판이 확장하지 않은 판보다 가난하지 않은 경우가 10판 중 6판이다. 손해 본 판은 1,700에서 53,000까지 잃었다.
2. **방치해도 손해가 적다.** 1년 뒤 방치한 판의 현금은 평균 59,520이다(v1.5는 32,140). 운영을 놓아도 계약금이 80%씩 꼬박꼬박 들어오기 때문이다.

이 밖에 전화만 있던 시절의 문구 3곳이 남아 있고, 점심 구간 앞부분에 화면 카드와 캐릭터가 서로 다른 상태를 보여 준다.

## 측정 (기준선 대 시험안, 시드 1–10)

| 항목 | 지금 | 시험안 |
|---|---|---|
| 방치 1년 현금 평균 | 59,520 | 34,120 |
| 합리적 1년 현금 평균 | 약 93,000 | 약 90,000 |
| 방치 1년 파산 | 1/10 | 1/10 |
| 확장 판이 가난하지 않음 | 6/10 | 9/10 |
| 확장 판 2년 현금 차이 평균 | 약 +4,100 | 약 +19,800 |

시험안은 아래 1과 2를 같이 넣은 것이다.

## 접근

**방치 손해** (검토한 것)

- **A. 계약금 삭감에 한 단계를 더한다 (선택).**
  - 지금: 달성일이 70% 미만이면 80%를 받는다.
  - 추가: 달성일이 40% 미만이면 60%만 받는다.
  - 실제 BPO의 단계별 SLA 페널티와 같은 모양이다. 서비스를 지키는 운영에는 거의 닿지 않는다.
- B. 해지 유예를 20근무일에서 10근무일로 줄인다. 방치뿐 아니라 잠깐 흔들린 운영까지 고객사를 잃게 된다.
- C. 만족도가 더 빨리 떨어지게 한다. 모든 점검의 바탕을 흔들어 다시 맞추는 범위가 크다.

**확장 이득** (검토한 것)

- **A. 확장 1단계 월세를 3,000에서 2,000으로 내린다 (선택).** 지은 뒤의 고정비가 줄어 늦게 지은 판도 본전을 찾는다.
- B. 공사비 30,000을 낮춘다. 한 번만 영향을 주어 늦게 지은 판에는 효과가 작다.
- C. 확장 뒤 새 고객사 제안을 빨리 오게 한다. 제안 흐름까지 건드린다.

## 범위

1. **계약금 단계**
   - 달성일 70% 미만: 80% (지금과 같음)
   - 달성일 40% 미만: 60% (새 단계)
   - 상수: `FEE_DEEP_BELOW = 0.4`, `FEE_DEEP_CUT = 0.6`
2. **확장 1단계 월세**: 3,000에서 2,000으로. 확장 2단계(2,000)와 공사비는 그대로 둔다.
3. **전화 시절 문구 3곳** (승인됨)

   | 위치 | 지금 | 바꿀 문구 |
   |---|---|---|
   | ui/text.js "상담 응대" 팁 | 고객사 전화를 받아요. | 고객사의 전화·채팅·메일을 맡아요. |
   | world/advisor.js 공사 시작 조언 | 공사하는 동안에도 전화는 와요. 배치는 평소처럼 챙겨 주세요. | 공사하는 동안에도 상담은 들어와요. 배치는 평소처럼 챙겨 주세요. |
   | world/events.js `game-over-clients` | …받을 전화가 없어 센터는 여기서 문을 닫아요… | …맡을 상담이 없어 센터는 여기서 문을 닫아요… (나머지 문장은 그대로) |

4. **점심과 휴식 카드 맞추기**
   - 사람 카드의 상태 글은 캐릭터와 같은 규칙을 따른다. 그 사람의 휴식 시간 안에서만 "휴식 중"이나 "점심 중"이고, 같은 30분 구간이라도 휴식 시간 밖이면 자리에 있는 상태로 보인다.
   - 판단 함수(`render/actors.js`의 `nowActivity`)를 화면 쪽과 같이 쓰는 모듈로 옮긴다.
   - 패널은 15분 칸이 바뀔 때마다 다시 그린다(휴식은 15분 단위).

## 하지 않을 것

평판 등급 기준, 해지 규칙, 만족도 변화량, 공사비, 확장 2단계는 바꾸지 않는다.

## 성공 확인

- 단위 테스트
  - 계약금 세 단계의 경계: 달성일 40%와 70% 바로 아래와 바로 위
  - 1단계 월세 2,000, 그 달에 완공했을 때 일할 계산
  - 문구 3곳
  - 카드 상태: 점심 구간 안에서 휴식 시간 전과 휴식 시간 중
- 자동 플레이 점검
  - 확장 점검의 "가난하지 않음" 기준을 6/10에서 8/10으로 되돌린다.
  - 새 점검을 추가한다. 방치 1년 현금 평균이 합리적 운영 평균의 절반 이하여야 한다(시험안: 약 38%).
  - 나머지 점검은 모두 통과해야 한다.
- `npm test`, 브라우저 점검. 주중 골든과 전화만 쓰는 화면 스냅숏은 바뀔 수 있으니 바뀐 내용을 확인한 뒤 다시 만든다.
