# v2.2.1 미룬 작은 문제 정리: 판단 기록

사용자가 2026-11-27에 "미룬 작은 문제 정리부터 추천 옵션으로 진행"이라고 요청했다. 출처는 v2.1과 v2.2 판단 기록의 "다음 버전으로 미룬 것"이다.

| 문제 | 해결 |
|---|---|
| 휴대폰 지표에서 채널 표시가 수치 줄 앞에 나옴 | CSS만 바꿨다. 이름과 채널을 같은 줄에 두고, 높이 0의 전체 폭 항목(`::before`)으로 그 뒤에서 줄을 바꾼다. |
| 탭 줄이 넘칠 때 옆에 더 있다는 표시가 없음 | 마지막 탭이 화면 밖으로 잘리면 `.more-right` 클래스로 오른쪽 끝을 흐리게 한다. 고른 탭은 보이도록 스크롤한다. |
| 화면 읽기 프로그램이 휴식 버튼을 읽을 때 사람 이름을 함께 읽지 않음 | 버튼 이름(`aria-label`)을 "이름 + 휴식 종류 + 15분 미루기/앞당기기"로 바꿨다. 이미 승인된 문구에 사람 이름만 붙였다. |

## 판단 (Ruling)

| 판단 | 이유 | 틀렸을 때 비용 |
|---|---|---|
| "더 있음" 판단은 스크롤 폭이 아니라 마지막 탭 버튼이 잘렸는지로 한다 | 끝까지 넘겨도 탭 줄 안쪽 여백(4px) 때문에 스크롤 폭 기준으로는 늘 "더 있음"이 되었다 | 없음 |
| 고른 탭을 보이게 스크롤하는 것도 넣었다 | 처음에는 이미 되는 줄 알았다. 점검이 앞 단계에서 탭 줄을 끝까지 넘겨 둔 탓에 우연히 통과했고, 처음 위치로 되돌리자 실패했다 | 없음 |

확인:
- npm test 552/552
- browser_check 통과(휴대폰 채널 줄과 탭 줄 점검 추가, 고치기 전 실패와 고친 뒤 통과를 확인)
- 시뮬레이션 코드는 바꾸지 않아 autoplay는 v2.2와 같다
