# v2.3 문구 초안: 휴식표 고정 규칙 (승인 필요)

자리표시: `{time}`은 시각(예: 12:30)이다.

## 휴식표 (`breaks`)

| 키 | 문구 |
|---|---|
| pinHelp | 📌를 누르면 그 휴식이 매일 같은 시간으로 고정돼요. 팀장은 고정된 휴식을 피해서 다른 사람 휴식을 짜요. |
| pin | 매일 이 시간으로 고정 |
| unpin | 고정 풀기 |
| pinned | 매일 |
| pinnedOff | 고정한 {time}이 오늘 근무 시간과 맞지 않아 팀장이 정했어요. |

버튼 이름(화면 읽기 프로그램용)은 v2.2.1과 같은 방식으로 붙인다. 예: "오르 카린타 점심 매일 이 시간으로 고정"

새 거절 문구는 없다. v1.9의 `not-working`과 `bad-break`를 쓴다.
