# On Behalf Inc

도트 그래픽의 2D 사무실에서 BPO 고객센터를 운영하는 시뮬레이션 게임입니다. 누구나 고객센터를 직접 꾸려 볼 수 있도록 만듭니다.

상담사, 팀장, QA는 저마다 특성과 기술을 가지고 있어요. 지치고, 아프고, 휴가를 가기도 합니다. 플레이어는 근무표와 업무 배치, 연구로 이들을 돌보고, 고객사의 서비스 레벨을 지켜 내야 합니다. 무대는 지구를 본뜬 가상의 행성입니다. 나라마다 다른 달력과 휴일이 직원의 결근과 고객의 콜 양을 함께 흔듭니다.
