# v1.8.1 미룬 작은 문제 정리: 판단 기록

계획: `2026-11-27-v1.8.1-polish.md`. 사용자가 2026-11-27에 "다음버전으로 미룬 작은 문제 추천옵션으로 해결진행"이라고 요청했다.

## 고친 것

| 출처 | 문제 | 해결 |
|---|---|---|
| v1.8 | 다른 고객사를 돕는 상담사가 휴식 구간의 자리 시간에 자기 채널로 보임 | 화면 정보에 `deskAnswering`을 추가했다. 목록과 캐릭터가 이것을 쓴다(`sim/away.js`의 `answeringAt`). |
| v1.8 | 버튼을 누른 뒤 다시 그린 목록이 직전 시각을 씀 | `minuteNow`에 함수도 받아 그릴 때마다 시계를 다시 읽는다. 게임 화면은 함수를 넘긴다. |
| v1.8 | `sim/away.js` 단독 테스트와 업무 탁자 경로 테스트가 없음 | `tests/away.test.js`와 actors 테스트를 추가했다. |
| v1.7 | 퇴사 예정 팀장과 새 팀장이 같은 팀장 책상에 겹쳐 그려짐 | 팀장 책상과 QA 책상은 한 명만 앉고, 두 번째 사람은 가까운 바닥에서 기다린다. |
| v1.7 | `leadHireVerdict`가 포기 콜 합계를 따로 계산함 | 공용 `dayTotal`을 쓴다. 점검 숫자는 같다. |
| v1.7 | 화면 정보에서 `needsLead`를 두 번 계산함 | 한 번만 계산한다. |

## 판단 (Ruling)

| 판단 | 이유 | 틀렸을 때 비용 |
|---|---|---|
| 한 명만 쓰는 자리 규칙을 팀장 책상과 QA 책상에만 적용 | 처음에는 다른 직원 모두에게 적용했는데, 퇴근하는 사람이 문 대신 바닥에 남았다. 화면 스냅숏 테스트가 잡아내 범위를 좁혔고, 문 테스트를 추가했다. | 없음 |
| 코칭 중인 팀장 둘은 원래 업무 탁자에서 서로 다른 자리에 앉음 | 리뷰가 지적한 겹침은 둘 다 책상에 있을 때(대기)만 생긴다. | 없음 |

확인: npm test 525/525, autoplay 23/23(숫자 변화 없음), browser_check 통과.
