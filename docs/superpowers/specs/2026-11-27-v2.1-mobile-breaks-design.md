# v2.1 휴대폰 화면 휴식표: 설계 (짧은 설계)

- 날짜: 2026-11-27
- 상태: 사용자가 범위로 "패널 + 휴식표 (추천)"을 골랐다(AskUserQuestion). 새 문구는 없다.

## 지금 상태 (폭 390px 스크린숏)

- 화면은 사무실과 알림이 나란히 놓이는 두 칸 구조다. 휴대폰에서는 사무실 칸 폭이 130px뿐이다.
- 탭을 누르면 패널이 그 사무실 칸 안에서 열린다. 폭 130px, 높이 약 90px라서 휴식표 표를 볼 수 없다.
- 브라우저 점검은 1280×720과 1024×640, 데스크톱 두 크기만 확인한다.

## 범위

**1. 휴대폰 패널 (폭 700px 이하, 모든 탭)**
- 패널은 사무실 칸이 아니라 화면 아래쪽 전체 폭에 붙는 시트로 열린다.
  - `position: fixed`, 왼쪽·오른쪽·아래 0
  - 최대 높이 75vh, 안쪽 세로 스크롤
- 넓은 표(근무표 등)는 패널 안에서 옆으로 스크롤된다. 문서 전체가 옆으로 밀리지 않는다.
- 탭 줄은 화면 맨 아래에 한 줄로 고정한다(옆으로 넘김, 높이 52px, 버튼 높이 44px 이상). 시트는 바로 그 위에 열리므로 패널을 연 채로 다른 탭을 누를 수 있다.
  - 실행 중 판단: 처음 구현에서는 시트가 탭 줄을 덮어, 탭을 바꾸려면 먼저 닫아야 했다. 브라우저 점검이 잡아냈다.
- 데스크톱(700px 초과)은 지금과 똑같다.

**2. 휴대폰 휴식표 (폭 700px 이하)**
- 같은 DOM(표)을 CSS로 카드처럼 보이게 한다.
  - 사람마다 한 덩어리이고, 첫 줄은 이름과 역할이다.
  - 아래에 휴식 세 줄이 온다(예: "오전 휴식  ◀ 10:30 ▶").
- 휴식 칸마다 `data-label`로 휴식 이름을 붙이고 CSS `::before`로 보여 준다. 휴식 이름은 이미 승인된 문구(`breaks.am/lunch/pm`)다.
- ◀ ▶ 버튼은 최소 44×44px로 누르기 쉽게 한다.
- 예상 콜 막대는 칸마다 최소 폭 22px이고, 막대 영역 안에서 옆으로 넘겨 본다.

## 하지 않을 것

- 사무실, 알림, 지표의 휴대폰 배치(게임 전체 휴대폰 화면은 다음 후보로 남긴다). 탭 줄은 위 판단대로 바꾼다.
- 끌어서 옮기기, 새 문구

## 성공 확인

- **단위 테스트**: 휴식 칸마다 `data-label`이 승인된 휴식 이름과 같다.
- **브라우저 점검에 휴대폰 크기(390×844) 추가**
  - 모든 탭: 패널 폭이 화면 폭과 같고, 문서가 옆으로 밀리지 않는다.
  - 휴식표 탭:
    - 휴식 버튼 높이 44px 이상
    - ▶ 클릭으로 15분 이동
    - 카드 배치일 때 표 머리글은 숨긴다.
  - 스크린숏을 확인한다.
- **데스크톱**: 기존 점검이 그대로 통과한다.
