# On Behalf Inc v1.3 — 새 문구 (채팅·이메일 채널)

상태: 승인 2026-11-25

- 날짜: 2026-11-25
- 쓰임: 설계 `2026-11-25-v1.3-channels-design.md`의 화면·세계 문구. 승인되면 그대로 `world/`와 `UI_TEXT`로 옮긴다.
- 읽는 법: 맨 왼쪽 칸이 영문 키(코드 이름)다. **한국어 문구만** 고쳐 주면 된다. "메모" 칸은 설명이며 화면에 나오지 않는다.
- 자리표시: `{client}` 고객사 이름, `{sl}` 목표, `{fee}` 월 계약금, `{n}` 숫자, `{pct}` 비율, `{hours}` 시간, `{name}` 사람 이름, `{research}` 연구 이름.
- 숫자는 모두 **가상 값**이며 밸런스 작업에서 다시 맞춘다. 숫자 뒤 조사(은/는, 예요/이에요)는 화면에서 자동으로 맞춘다.
- 기존 승인 문구는 바꾸지 않는다.
