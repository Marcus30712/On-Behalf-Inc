# v2.2 게임 전체 휴대폰 화면: 판단 기록

- 설계: `../specs/2026-11-27-v2.2-mobile-layout-design.md`(짧은 설계로, 계획 역할도 함께 한다)

## 판단 (Ruling)

| 판단 | 이유 | 틀렸을 때 비용 |
|---|---|---|
| 사무실 그림은 화면 폭에 맞춘다. 확대 버튼이나 옆으로 넘기기는 넣지 않는다 | 사무실 전체가 한눈에 보이고, 새 문구가 필요 없다. 지금보다 3배 크다 | 사람이 아직 작다(폭 약 20px). 누르는 범위를 넓혀 보완했다 |
| `.office` 스타일을 `section.office`로 좁혔다 | v1.2부터 패널의 확장 구역 스타일이 캔버스(`canvas.office`)에도 붙어 그림을 21px 아래로 밀고 9px 눌러 그렸다. 데스크톱에서도 마찬가지였다 | 데스크톱 화면에서 사무실이 21px 위로 올라가고 바르게 그려진다. 점검은 모두 통과한다 |
| 휴대폰에서는 알림이 지표보다 먼저 온다 | 최종 검토: 고객사가 7곳이면 지표 때문에 알림이 화면 밖으로 밀렸다 | 지표를 보려면 조금 내려야 한다 |
| 넓은 누르기 범위는 휴대폰 배치에서만 쓴다 | 최종 검토: 800×600 같은 작은 데스크톱 창에도 켜졌다. 브라우저 탐색으로 고치기 전 켜짐, 고친 뒤 꺼짐을 확인했다 | 없음 |
| 휴대폰 알림 안쪽 목록의 높이 제한을 풀었다(`.inbox .inbox { max-height: none }`) | 최종 검토: 바깥 알림 칸의 45vh 제한이 안쪽 목록에도 붙어 내용이 제 칸 밖으로 넘쳤다. 같은 규칙을 고치는 김에 함께 고쳤다 | 없음 |

## 다음 버전으로 미룬 것

- 휴대폰 지표에서 채널 표시(📞 전화 등)가 이름 줄이 아니라 숫자 줄 앞에 나온다(설계는 이름 줄).
- 탭 줄이 넘칠 때 옆에 더 있다는 표시가 없다(v2.1부터).
- 화면 읽기 프로그램이 휴식 버튼을 읽을 때 사람 이름을 함께 읽지 않는다(v2.1부터).

확인: npm test 552/552, autoplay 23/23, browser_check 통과(데스크톱 2개 크기와 휴대폰 390×844, 그림 위치 점검 포함), 스크린숏 확인.
