## 판단 (Ruling)

| 작업 | 판단 | 이유 | 틀렸을 때 비용 |
|---|---|---|---|
| 계획 | 이메일 밀림 상태는 `{ openMin, items:[{at,n}], carry }` (+ 경고 간격용 `warnedAt`) | 고객사별 영업 분 시계와 소수 처리량이 필요 | 없음 (내부 형태) |
| 계획 | 이메일 만족도는 하루 한 번이 아니라 30분마다 전화와 같은 경로로 움직임 | 기존 경로 재사용 | 하루 단위보다 완만 |
| 3 | 늦은 메일은 기한을 넘기는 순간 한 번만 셈 | 두 번 세면 기한 안 답장 비율이 실제 50%일 때 33%로 보였음 | 없음 |
| 4 | 효과 없는 연구(채팅·메일 창구) 완료 문장의 `{name}`은 첫 상담사로 채움; 조언의 "얼굴이 달라졌죠?" 줄은 쓰지 않음 | 승인 문장이 보이도록, 바뀐 사람이 없으니 조언은 빼고 | 없음 |
| 5 | 채널 표시는 채팅·이메일 고객사가 생긴 뒤에만 보임 | 전화만 하는 화면은 v1.2와 같게 | 없음 |
| 5 | 채팅·이메일 일도 "전화 응대"로 표시 | 승인된 중립 이름이 없음 → 다음 문구 승인 때 여쭤볼 것 | 표현이 조금 어색 |
| 6 | 이메일은 하루 84통 × 6분: 제대로 하려면 2명, 한 명당 6,000 | 한 명당 12,000이던 "거의 공짜 돈"을 다른 고객사(4,500~6,000) 수준으로 | 2명 고정 기준이 85통에서 7/10으로 꺾이는 경계 근처 |
| 6 | 채팅 고객사는 확장 1, 이메일 고객사는 확장 2 이후에 제안 (설계 §4.1 수정) | 좌석이 없을 때 온 제안을 거절하면 재제안 뒤로 밀려 2년 안에 회복 못 함 | 채널이 게임 후반에 옴 |
| 6 | 돈 기준: 10판 평균 현금이 채널 없는 운영 이상 (판별 개수는 기록만) — **사용자 결정** | 판별 8/10 기준은 세 번 조정해도 못 넘음 | 일부 판에서는 본전 수준 |
| 최종 | 고객사를 잃으면 밀린 메일을 비움 | 다시 받아도 예전 메일 때문에 반드시 다시 잃었음 | 없음 |
| 최종 | 들어온 메일 수를 따로 셈 | 밀린 메일이 있는데 "아직 메일이 없어요"가 보였음 | 없음 |
| 최종 | 문의 폭주 사건은 전화 고객사에만 | 사건 문구가 전화 전용; 난수 순서는 그대로 | 채널에는 폭주가 없음 |
| 최종 | 연구 설명 끝 문장을 "사무실을 한/두 번 넓히면 … 제안이 와요"로 — **사용자 승인** | 연구 후 100~250일 동안 아무 일도 없어 보였음 | 없음 |

## 숫자 요약 (시드 1~10, 720일)

- 채널 운영 평균 현금 212,240 / 채널 없는 운영 204,960.
- 2년 차 수수료 전액 비율: 채널 68.4% / 채널 없음 89.3% — 좌석을 나눠 쓰는 만큼 전화 품질이 떨어진다.
- 이메일 2명 고정(대체 근무 없음): 10/10 유지, 새 시드 31~50에서 16/20.

## 다음 버전으로 미룬 것

- "전화 응대"를 채널 중립 이름으로 바꾸는 문구 승인, 이탈 경고 조언·세 번째 고객사 이정표 문구 점검.
- 고객사 5곳 이상일 때 1280×720에서 지표 줄이 몇 px 넘침(기존에도 5 px 넘침).
- 전화 주말 고객사를 돕는 채팅·이메일 상담사에게 💬/✉️ 표시가 남음.
- 이메일 SL이 1+1e-12가 될 수 있음(화면 영향 없음); 불러온 밀림 형태 검증 없음.
- `channelLabel`·도움받은 이름 합치기 코드 중복, 지도 표시의 캔버스 상태 저장 누락.
- 자동 플레이가 약 230초로 길어짐.
