# v2.4 문구 초안: QA 채용 (승인 필요)

v1.7 팀장 채용 문구와 같은 모양이다. 자리표시:
- `{cost}`: 돈
- `{n}`: 근무일
- `{t1}`, `{t2}`: 특성 문구(아래 `traits` 또는 `noTraits`)

## 채용 탭 (`hiring.qa`)

| 키 | 문구 |
|---|---|
| title | QA 채용 |
| missing | 지금은 QA가 없어요. 통화 점검이 멈춰서 고객사 만족도가 덜 올라요. |
| leaving | QA가 곧 떠나요. 지금 새 QA를 찾기 시작할 수 있어요. |
| help | QA는 통화를 점검해 실수를 줄이고 고객사 만족도를 올려요. 며칠 뒤 지원자 두 명이 오면 한 명을 고를 수 있어요. |
| cost | QA 채용 비용 💰 {cost} |
| start | QA 채용 시작 |
| searching | QA 지원자를 찾는 중 · {n}근무일째 |
| traits | 특성 {list} |
| noTraits | 특별한 특성 없음 |

"다른 채용이 끝나면 시작할 수 있어요."는 v1.7 문구(`hiring.lead.busy`)를 함께 쓴다.

## 사람 탭 경고 (`people.noQa`)

QA 없음 · 통화 점검이 멈춰 있어요. 상담사에게 QA 업무를 맡길 수도 있어요.

## 알림 `qa-candidate`

- 제목: QA 지원자 두 명이 왔어요
- 본문: {cand1} 씨({t1})와 {cand2} 씨({t2})가 QA 자리에 지원했어요. 누구와 함께할까요?

| 선택지 | 결과 |
|---|---|
| {cand1} 씨를 뽑는다 | {cand1} 씨가 QA로 들어와요. 통화 점검을 맡아요. |
| {cand2} 씨를 뽑는다 | {cand2} 씨가 QA로 들어와요. 통화 점검을 맡아요. |
| 이번엔 보류한다 | 아무도 뽑지 않아요. 다시 뽑으려면 QA 채용을 새로 시작해야 해요. |

## 김미소 조언

| 키 | 문구 |
|---|---|
| qa-candidate | QA는 꼼꼼함이 중요해요. 꼼꼼한 사람은 같은 시간에 통화를 더 많이 점검해요. |
| resign-notice-qa | QA가 떠나면 통화 점검이 멈춰요. 채용 탭에서 새 QA를 찾거나, 그동안 상담사에게 QA를 맡겨요. |
