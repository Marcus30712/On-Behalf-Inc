# v1.9 Break Editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add a 휴식표 tab where the player sees today's forecast and break plan and moves each break 15 minutes at a time.

**Architecture:**
- The sim gets a `moveBreak` action that edits today's kept plan (`state.breaks`) and a pure `breakBoard(state)` for the view.
- The UI adds a `breaks` tab next to the roster.
- The interval already reads the kept plan, so edits take effect with no change there.

**Tech Stack:** vanilla ES modules, `node --test` + jsdom, tools/browser_check.py.

**Spec:** `docs/superpowers/specs/2026-11-27-v1.9-break-editor-design.md`. Approved copy: `docs/superpowers/specs/2026-11-27-v1.9-copy.md`.

## Global Constraints

- Copy is verbatim from the approved copy doc.
- Grid is 15 minutes. Windows come from `windowsFor(shift length)`, offset by the shift start.
- Refusal reasons are checked in this order: `unknown-person`, `not-working`, `bad-break`, `break-started`, `break-window`.
- Moving to a start equal to now is allowed; now = `state.minute + pendingMinutes` (the screen clock; final-review ruling). A break whose current start is earlier than now cannot move.
- `edited: true` is stored on the entry for today only.
- Busy slot: the slot's forecast is in today's top 25% of open slots, and `away >= 2`.
- No balance change: autoplay stays 23/23 with the same numbers. `VERSION` stays 1.

## Review Focus

1. A move to a start equal to the window's first or last start is allowed; one step past it is refused → Task 1 test.
2. Someone working today with no kept entry (put on shift during the day) gets an entry when they are moved → Task 1 test.
3. The interval uses the edited start: at the new start the person is on break, and at the old start they are not → Task 1 test.
4. A v1.8 save with `breaks` and no `edited` loads, and the board works → Task 1 test.
5. The ◀ button is disabled at the window edge or when the break has started → Task 2 test.
