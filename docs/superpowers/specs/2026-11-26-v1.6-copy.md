# On Behalf Inc v1.6 — 새 문구 (휴식 배정)

상태: 승인 2026-11-26 ("나머지 승인")

- 날짜: 2026-11-26
- 쓰임: 설계 `2026-11-26-v1.6-breaks-design.md`. 승인되면 그대로 `UI_TEXT`·`world/`로 옮긴다.
- 자리표시: `{am}` 오전 휴식 시각, `{lunch}` 점심 시각, `{pm}` 오후 휴식 시각 (예: 10:15).

| 키 | 문구 | 쓰이는 곳 |
|---|---|---|
| `skill.planning.name` | 스케줄링 | 사람 카드 기술 |
| `skill.planning.tip` | 휴식 시간을 짜는 솜씨. 팀장이 높을수록 콜이 몰리는 시간을 피해 휴식을 배정해요. | 기술 툴팁 |
| `card.breaksToday` | 오늘 휴식 | 사람 카드 줄 이름 |
| `card.breaksLine` | 휴식 {am} · 점심 {lunch} · 휴식 {pm} | 사람 카드 |
| `card.breaksNone` | 오늘은 근무가 없어요. | 쉬는 날 |
| `activity.lunch` | 점심 중 | 사람 목록·카드 상태 |
| 사건 `breaks-auto` 제목 | 휴식 자동 배정 | 평일에 팀장이 없을 때 |
| 사건 `breaks-auto` 본문 | 오늘은 팀장이 자리에 없어 휴식 시간이 무작위로 정해졌어요. 콜이 몰리는 시간에 자리가 빌 수 있어요. | |
| 조언 `breaks-auto` | 팀장이 없는 날엔 휴식표가 엉성해져요. 오늘은 서비스 레벨을 자주 봐 주세요. | 김미소 선배 |

머리 위 직급 이름표는 새 문구 없이 기존 `role.agent`(상담사)·`role.lead`(팀장)·`role.qa`(QA)를 쓴다.
