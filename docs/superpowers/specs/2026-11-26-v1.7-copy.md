# v1.7 문구 초안 — 팀장 채용 (승인 필요)

숫자 자리표시: {cost}는 돈, {n}은 근무일, {c1}·{p1}는 코칭·스케줄링이며 소수점 2자리로 표시한다.

## 채용 탭 (ui/text.js `hiring.lead`)

| 키 | 문구 |
|---|---|
| title | 팀장 채용 |
| missing | 지금은 팀장이 없어요. 휴식이 무작위로 정해지고 코칭도 멈춰 있어요. |
| leaving | 팀장이 곧 떠나요. 지금 새 팀장을 찾기 시작할 수 있어요. |
| help | 팀장은 휴식표를 짜고 상담사를 코칭해요. 며칠 뒤 지원자 두 명이 오면 한 명을 고를 수 있어요. |
| cost | 팀장 채용 비용 💰 {cost} |
| start | 팀장 채용 시작 |
| searching | 팀장 지원자를 찾는 중 · {n}근무일째 |
| busy | 다른 채용이 끝나면 시작할 수 있어요. |

## 사람 탭 경고 (`people.noLead`)

팀장 없음 · 휴식이 무작위로 정해지고 있어요.

## 알림 `lead-candidate` (world/events.js)

- 제목: 팀장 지원자 두 명이 왔어요
- 본문: {cand1} 씨(코칭 {c1} · 스케줄링 {p1})와 {cand2} 씨(코칭 {c2} · 스케줄링 {p2})가 팀장 자리에 지원했어요. 누구와 함께할까요?

| 선택지 | 결과 |
|---|---|
| {cand1} 씨를 뽑는다 | {cand1} 씨가 팀장으로 들어와요. 휴식표와 코칭을 맡아요. |
| {cand2} 씨를 뽑는다 | {cand2} 씨가 팀장으로 들어와요. 휴식표와 코칭을 맡아요. |
| 이번엔 보류한다 | 아무도 뽑지 않아요. 다시 뽑으려면 팀장 채용을 새로 시작해야 해요. |

## 김미소 조언 (world/advisor.js)

| 키 | 문구 |
|---|---|
| lead-candidate | 휴식표는 팀장 솜씨예요. 스케줄링이 높을수록 바쁜 시간을 잘 피해서 쉬게 해요. |
| resign-notice-lead | 팀장이 떠나면 휴식표를 짤 사람이 없어요. 채용 탭에서 새 팀장을 미리 찾아 둬요. |
