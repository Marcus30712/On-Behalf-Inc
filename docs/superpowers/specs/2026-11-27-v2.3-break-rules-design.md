# v2.3 휴식표 고정 규칙: 설계

- 날짜: 2026-11-27
- 상태: 초안. 사용자가 다음 버전으로 "휴식표 고정 규칙"을 골랐다. 문구는 `2026-11-27-v2.3-copy.md`에서 따로 승인받는다.
- 이어지는 버전: v1.9 휴식표 직접 조정(하루 단위), v2.1–v2.2 휴대폰 화면

## 의도

v1.9에서는 오늘 휴식만 옮길 수 있다. 실제 센터에서는 "김 상담사 점심은 매일 12:30"처럼 사람마다 정해 둔 휴식이 있다. 매일 같은 손질을 반복하지 않도록, 휴식 하나를 "매일 이 시간"으로 고정할 수 있게 한다. 팀장은 고정된 휴식을 먼저 놓고, 나머지 사람의 휴식을 그것을 피해서 짠다.

## 목표 / 하지 않을 것

- **목표**
  - 휴식표에서 사람마다 휴식 종류(오전 휴식, 점심, 오후 휴식)별로 지금 시각을 "매일 이 시간"으로 고정하거나 고정을 푼다.
  - 다음 날부터 팀장이 휴식표를 짤 때 고정된 휴식이 그 시각에 들어가고, 다른 사람은 그것을 피해서 짜인다.
- **하지 않을 것**
  - 요일별 규칙(예: 월요일만)
  - 근무조별로 다른 규칙
  - "모든 사람 점심 12시" 같은 일괄 규칙
  - 휴식 길이 바꾸기
- **피할 것**
  - 고정이 하나도 없을 때 휴식 배정이 조금이라도 바뀌는 것. 밸런스, 자동 플레이, 주중 골든이 그대로여야 한다.

## 접근 (검토한 것)

1. **고정 휴식을 먼저 놓고 나머지를 짠다 (선택).** 고정 휴식이 미리 자리를 차지한 상태에서 팀장이 다른 사람의 휴식을 짠다. 팀장의 스케줄링 능력은 고정되지 않은 휴식에만 쓰인다. 실제 운영과 같다.
2. 팀장이 다 짠 뒤 고정 시각으로 덮어쓴다. 코드는 간단하지만, 다른 사람의 휴식이 고정 시각과 겹쳐 바쁜 칸이 생길 수 있다.
3. 시각 대신 "근무 시작부터 몇 분 뒤"로 고정한다. 근무조가 바뀌어도 맞지만, "매일 이 시간"이라는 말과 다르다.

## 규칙

- **저장**: `state.breakRules = { [personId]: { am?, lunch?, pm? } }`. 값은 그날 0시부터 센 분(시각)이다. 세이브에 남고, VERSION은 1 그대로다. 필드가 없으면 규칙이 없는 것이다.
- **행동**
  - `pinBreak { personId, kind }`
    - 오늘 그 사람의 그 휴식 시각을 규칙으로 저장한다.
    - 거절 사유는 `unknown-person`, `not-working`, `bad-break`다(v1.9와 같은 문구).
    - 오늘 휴식표는 그대로다(이미 그 시각이다).
  - `unpinBreak { personId, kind }`: 규칙을 지운다. 오늘 휴식표는 그대로다.
  - `moveBreak`: 고정된 휴식을 옮기면 규칙도 새 시각으로 바뀐다. 화면에 보이는 시각이 곧 매일 시각이다.
- **휴식표를 짤 때** (`planBreaks`)
  - 먼저 고정 휴식을 놓는다. 그날 근무조의 휴식 범위 안에 드는 규칙만 놓는다.
  - 그다음 지금과 같은 방식으로 나머지 휴식을 짠다. 이미 놓인 고정 휴식은 "그 시간에 자리에 없는 사람"으로 계산된다.
  - 범위에 들지 않는 규칙(예: 이른 조 시각인데 오늘은 늦은 조)은 그날 쓰지 않고 팀장이 정한다. 규칙은 지우지 않는다.
  - 무작위 뽑기 순서는 고정 여부와 상관없이 같게 둔다. 그래서 고정이 없으면 결과가 지금과 똑같다.
- **사람이 떠나면** 그 사람의 규칙을 지운다.

## 휴식표 화면

- 휴식 칸마다 📌 버튼을 둔다(누르면 켜고 끄기, `aria-pressed`). 켜져 있으면 시각 옆에 "매일" 표시가 붙는다.
- 규칙이 있지만 오늘 근무와 맞지 않아 쓰지 않았으면, 그 칸에 짧은 안내를 보여 준다.
- 도움말 아래에 고정을 설명하는 한 줄을 더한다.
- 휴대폰 카드에서도 같은 버튼을 쓴다(44px).

## 성공 확인

- **단위 테스트**
  - 고정·풀기와 거절 사유
  - 다음 날 고정 시각이 쓰임
  - 고정된 휴식을 옮기면 규칙도 바뀜
  - 범위 밖 규칙은 그날 쓰지 않음(규칙은 남음)
  - 고정 휴식을 피해서 짬: 상담사 두 명의 점심을 같은 시각에 고정하면, 다른 상담사는 그 시각을 피한다(팀장 스케줄링 8)
  - 고정이 없으면 계획이 전과 같음(주중 골든)
  - 떠난 사람의 규칙은 지워짐
  - 세이브 불러오기(규칙 있음, 규칙 없음, 잘못된 규칙은 버림)
- **화면 테스트**: 📌 버튼과 `aria-pressed`, "매일" 표시, 범위 밖 안내
- **브라우저 점검**(데스크톱과 휴대폰): 📌를 누른 뒤 하루를 넘기면 같은 시각이다.
