# v2.2 게임 전체 휴대폰 화면: 설계 (짧은 설계)

- 날짜: 2026-11-27
- 상태: 사용자가 "게임 전체 휴대폰 화면 버전 진행"이라고 했다. 새 문구는 없다.
- 이어지는 버전: v2.1(휴대폰 패널 시트, 아래 탭 줄, 휴식표 카드)

## 지금 상태 (폭 390px)

- 사무실과 알림이 두 칸으로 나란히 놓인다. 사무실 칸은 폭 130px로, 사무실 그림이 왼쪽 위에 아주 작게 보인다.
- 고객사 지표는 한 줄에 여러 값이 늘어서서 어색하게 접힌다.
- 사람을 누르는 범위는 그림 크기 그대로다. 폭 130px에서는 사람 한 명이 약 6px라 누르기 어렵다.

## 접근 (검토한 것)

**사무실 그림**
- **A. 화면 폭에 맞춘다 (선택).** 폭 390px이면 그림 폭도 390px이 되어 지금의 3배 크기다. 사무실 전체가 한눈에 보인다.
- B. 더 크게 그리고 옆으로 넘긴다. 사람은 더 크게 보이지만 사무실 전체를 보려면 넘겨야 하고, 넘기는 손짓과 사람을 누르는 손짓이 겹친다.
- C. 확대 버튼을 둔다. 새 문구와 상태가 필요해서 이번 범위를 넘는다.

**사람 누르기**
- 휴대폰처럼 그림을 작게 줄여 보여 줄 때는 누르는 범위를 반 칸(24 그림 px)만큼 넓힌다. 범위 안에 여러 명이 있으면 그림 중심에서 가장 가까운 사람을 고른다. 데스크톱에서는 지금과 같다.

## 범위 (폭 700px 이하만)

1. **한 칸 배치.** 위에서부터 위 막대, 사무실, 고객사 지표, 알림 순서다. 탭 줄과 패널 시트는 v2.1 그대로다.
2. **사무실.** 그림이 화면 폭을 꽉 채운다.
3. **알림.**
   - 사무실 아래 전체 폭에 놓인다.
   - 높이는 내용만큼이고 최대 45vh다. 넘치면 안에서 스크롤한다.
   - 왼쪽 경계선 대신 위쪽 경계선을 쓴다.
4. **고객사 지표.**
   - 고객사마다 한 덩어리다. 첫 줄은 이름과 채널이고, 값들은 다음 줄로 접힌다.
   - 문서가 옆으로 밀리지 않는다.
5. **위 막대.** 간격을 줄인다(지금도 두 줄로 접히는 것은 그대로).
6. **사람 누르기.** `personAt(actors, x, y, slop)`를 쓴다. 화면 폭이 그림 폭의 60%보다 작게 보이면 `slop`은 반 칸이다.

## 하지 않을 것

- 데스크톱(700px 초과)과 가로로 눕힌 휴대폰의 배치
- 확대·축소 손짓
- 새 문구

## 성공 확인

- **단위 테스트:** `personAt`에서
  - `slop`이 0이면 지금과 같다;
  - `slop` 안의 가장 가까운 사람을 고른다;
  - `slop` 밖이면 아무도 고르지 않는다.
- **브라우저 휴대폰 점검(390×844)에 추가**
  - 그림 폭 = 화면 폭
  - 알림이 그림 아래에 있고 폭이 화면 폭과 같다
  - 지표 때문에 문서가 옆으로 밀리지 않는다
  - 그림에서 사람을 누르면 사람 카드가 열린다
  - 스크린숏을 확인한다
- **그 밖:** 데스크톱 점검은 그대로 통과한다. `npm test`, 자동 플레이 23/23.
