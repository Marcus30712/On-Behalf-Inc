# On Behalf Inc — 세계관 문안

- 날짜: 2026-11-24
- 상태: 승인 2026-11-24
- 승인 때 정한 것: 화면 요일은 월화수목금토일(아래 1.2의 B안). 고요의 달에 `staffAvail: 0.8` 칸을 더함. 퇴사 예고 붙잡기·채용 보류는 이 문안대로.
- 쓰임: 계획 Task 1의 결과물. 승인되면 Task 5가 이 문안을 `world/` 데이터로 그대로 옮긴다.
- 읽는 법: 표마다 맨 왼쪽 칸이 영문 id(코드에서 쓰는 이름)다. id는 바꾸지 않아도 되고, 한국어 문안만 고쳐 주면 된다. 숫자는 모두 **가상 값**이며 밸런스 단계(Task 13)에서 다시 맞춘다.

**이 행성이 지구를 본뜨는 방식.** 무대는 가상의 행성 엘로반이다. 지구의 다양함에서 가져온 것은 **운영에 주는 모양**뿐이다. 어떤 나라는 고정된 날짜의 달력을 쓰고 어떤 나라는 해마다 날짜가 앞당겨지는 달력을 쓴다는 것, 주말이 토·일인 곳과 금·토인 곳이 있다는 것, 며칠씩 이어지는 새해 연휴, 한 달 내내 일찍 퇴근하는 기간, 연휴 동안 콜이 줄었다가 끝나면 몰리는 흐름 같은 것들이다. 이름, 의식, 옷차림, 상징, 신앙, 글자는 하나도 가져오지 않고 새로 지었다. 휴일의 성격은 "가족과 모인다", "수확을 축하한다", "선물을 보낸다"처럼 어느 문화에나 있을 법한 생활 모습으로만 적었다. 출신 나라는 그 사람의 달력과 쉬는 날만 정하고, 능력·성격·기술에는 전혀 영향을 주지 않는다.

| `churn-warning` | {client}가 계약 해지를 경고했어요 | {client}의 만족도가 바닥까지 내려갔어요. {days}근무일 안에 나아지지 않으면 계약을 끝내겠대요. |
| `research-done` | {research} 연구 완료 | {research} 연구가 끝났어요. 바로 공사를 시작해요. {hours}시간 뒤에 완공돼요. |
| `build-done` | {research} 완공 | (연구별 완료 알림 `doneText`를 그대로 보여 준다. 6장 참고) |
| `game-over-cash` | 센터 문을 닫아요 | 돈이 바닥나 이번 달 급여를 줄 수 없어요. 센터는 여기서 문을 닫아요. 함께한 {days}일, 고마웠어요. |
| `game-over-clients` | 마지막 고객사가 떠났어요 | 남은 고객사가 하나도 없어요. 받을 전화가 없어 센터는 여기서 문을 닫아요. 함께한 {days}일, 고마웠어요. |
| `milestone-big-client` | 이정표: 고객사 세 곳 | 이제 고객사 세 곳의 전화를 함께 받아요. 작은 센터가 여기까지 왔어요. |
| `milestone-rank-s` | 이정표: 평판 S등급 | 평판이 S등급에 올랐어요. 모두가 함께 만든 결과예요. |

### 7.2 선택지 있는 사건

| 사건 id | 제목 / 본문 | 선택지 id | 선택지 문안 (`label`) | 결과 요약 (`result`) |
|---|---|---|---|---|
| `holiday-leave` | **{name} 씨의 휴가 신청** / 내일부터 {holiday}예요. {name} 씨가 고향 가족과 보내려고 휴가를 신청했어요. | `grant` | 휴가를 허락한다 | {name} 씨가 휴가를 떠나요. 사기가 올라요. |
| | | `refuse` | 이번엔 근무를 부탁한다 | {name} 씨의 사기가 크게 떨어져요. 그날 결근할 수도 있어요. |
| `friday-off` | **금요일 휴무 요청** / {nation}에서는 별날(금)이 쉬는 날이에요. {name} 씨가 이번 별날에 쉬고 싶어 해요. | `change` | 근무표를 바꿔 준다 | {name} 씨의 사기가 올라요. 그날 근무 인원은 한 명 줄어요. |
| | | `keep` | 그대로 둔다 | 근무표는 그대로예요. {name} 씨의 사기가 조금 내려가요. |
| `resign-notice` | **{name} 씨의 퇴사 예고** / {name} 씨가 {days}근무일 뒤에 그만두겠다고 했어요. 많이 지쳐 보여요. | `keep-trying` | 면담하고 붙잡아 본다 | 따로 시간을 내 이야기를 들어요. 사기가 다시 오르면 마음을 바꿀 수도 있어요. |
| | | `let-go` | 보내 준다 | 마지막 날까지 잘 마무리하도록 도와요. {days}근무일 뒤 {name} 씨가 떠나요. |
| `candidate` | **지원자 두 명이 왔어요** / {cand1} 씨와 {cand2} 씨가 면접을 봤어요. 누구와 함께할까요? | `pick-1` | {cand1} 씨를 뽑는다 | {cand1} 씨가 수습 상담사로 들어와요. 처음 두 주는 교육이 필요해요. |
| | | `pick-2` | {cand2} 씨를 뽑는다 | {cand2} 씨가 수습 상담사로 들어와요. 처음 두 주는 교육이 필요해요. |
| | | `hold` | 이번엔 보류한다 | 아무도 뽑지 않아요. 다시 뽑으려면 채용을 새로 시작해야 해요. |
| `client-offer` | **새 고객사 제안** / {client}에서 계약을 제안했어요. 목표는 {sl}, 월 계약금은 {fee}예요. 좌석이 8개뿐이라 지금 인원을 나눠야 해요. | `accept` | 계약한다 | {client}가 새 고객사가 돼요. 상담사를 세 고객사에 나눠 배치하세요. |
| | | `decline` | 정중히 거절한다 | 지금 인원으로 지금 고객사에 집중해요. |

> 확인 필요:
> - `resign-notice`의 `keep-trying` 효과는 계획에 숫자가 없다. 제안: 사기 +15, 퇴사일까지 사기가 50을 넘으면 퇴사 예고 철회.
> - `candidate`의 `hold`에서 채용 비용(가상 값 1,500)을 돌려줄지 계획에 없다. 위 문안은 "돌려주지 않음"을 전제로 썼다.
> - 지원자 카드에 특성 1~2개를 미리 보여 주면 고르는 재미가 생긴다(문안 변경 없음, 화면에서 처리).

## 8. 김미소 조언 (`ADVISOR`)

김미소는 오래 일한 선배 운영 매니저다. 플레이어를 "센터장님"이라 부른다. 사건마다 한두 줄 중 하나가 무작위로 나온다.

| 사건 id | 김미소의 한마디 |
|---|---|
| `sick` | 아픈 건 누구 잘못도 아니에요. 오늘은 남은 사람들 배치만 다시 봐 주세요. |
| | 의무실 연구가 있으면 이런 날이 훨씬 짧아져요. |
| `burnout` | 번아웃은 하루아침에 오지 않아요. 스트레스 막대가 오래 빨갛던 사람을 먼저 챙겨 주세요. |
| | {name} 씨가 돌아오면 첫 주는 조금 가볍게 맡겨 주세요. |
| `no-show` | 혼내기 전에 먼저 안부를 물어봐요. 이유가 있을 거예요. |
| `argument` | 한 통화로 사람을 판단하지 말아요. 요즘 {name} 씨가 얼마나 지쳤는지 먼저 봐 주세요. |
| | 코칭 시간을 조금만 내 주면 다음엔 달라질 거예요. |
| `resign-notice` | 정든 사람을 보내는 건 늘 아파요. 붙잡든 보내든, 이야기는 꼭 들어 주세요. |
| | 사람이 떠나는 이유는 대개 돈보다 피로예요. |
| `holiday-leave` | 명절에 가족을 못 보면 일도 손에 안 잡혀요. 웬만하면 보내 주세요. |
| | 휴일 달력을 미리 보면 이런 날을 대비할 수 있어요. |
| `friday-off` | 우리 센터의 주말과 {name} 씨의 주말이 달라요. 서로 조금씩 맞춰 가요. |
| `call-spike` | 연휴 다음 날은 늘 이래요. 덜 바쁜 고객사에서 한두 명 옮겨 와요. |
| | 대기 시간이 길어지면 끊는 고객이 늘어요. 지금은 전화부터요. |
| `client-offer` | 큰 기회예요. 다만 지금 인원으로 버틸 수 있는지 먼저 따져 봐요. |
| `churn-warning` | 아직 늦지 않았어요. 그 고객사에 사람을 더 붙이고 서비스 레벨부터 올려요. |
| `research-done` | 연구 끝! 공사만 끝나면 바로 효과가 나요. |
| `build-done` | 보세요, {name} 씨 얼굴이 달라졌죠? 이게 센터장님이 한 일이에요. |
| `candidate` | 기술은 가르치면 늘어요. 우리 팀과 잘 맞을 사람을 골라요. |
| `game-over-cash` | 이번엔 여기까지예요. 그래도 많이 배웠잖아요. 다시 해 봐요, 센터장님. |
| `game-over-clients` | 고객사가 떠난 건 아프지만, 무엇이 흔들렸는지 이제 알잖아요. 다시 시작해요. |
| `milestone-big-client` | 고객사 세 곳이라니! 처음 문 열던 날이 생각나네요. |
| `milestone-rank-s` | S등급이에요. 사람을 아껴서 얻은 등급이라 더 값져요. |
