# v1.8 Balance Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make an idle center lose more money, make expansion pay off, replace three phone-only copy lines, and make the person card agree with the sprite during breaks.

**Architecture:** Add a deeper fee tier in `monthEnd` and lower the level 1 rent. Move the minute-aware break check out of render into a shared pure module that both the sprite and the card use, and have the panel redraw once per 15-minute slot.

**Tech Stack:** vanilla ES modules, `node --test` + jsdom, tools/autoplay.js, tools/browser_check.py.

**Spec:** `docs/superpowers/specs/2026-11-27-v1.8-balance-design.md`

## Global Constraints

- `FEE_CUT_BELOW = 0.7` → `FEE_CUT = 0.8`; new: `FEE_DEEP_BELOW = 0.4` → `FEE_DEEP_CUT = 0.6`. A share exactly at a threshold is not below it.
- Level 1 rent 2000. Level 1 cost 30000, level 2 unchanged.
- Copy is verbatim from the spec table. No other copy changes.
- `VERSION` stays 1.

## Review Focus

1. Share exactly 0.4 or 0.7 → the higher tier (not cut deeper) → Task 1 test.
2. A month finished mid-way at level 1 prorates 2000, not 3000 → Task 1 test.
3. Card with no break plan (`p.breaks` missing, a v1.5 save) → same text as before → Task 3 test.
4. Card for someone on a channel task or off shift → unchanged → existing tests in Task 3 must stay green.
5. The panel redraws when the 15-minute slot changes, even if the sim minute (interval) does not → Task 3 test.
