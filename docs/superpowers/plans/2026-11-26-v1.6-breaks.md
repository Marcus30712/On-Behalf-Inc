# v1.6 Break Scheduling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The team lead schedules each person's 15/60/15-minute breaks every day around forecast call volume, with quality set by the lead's new 스케줄링 skill; random when the lead is away; breaks shown on cards; role tag over heads; calmer movement.

**Architecture:** New pure module `sim/breaks.js` builds `state.breaks[day] = { [personId]: { am, lunch, pm, by } }` at day start; `schedule.workShare` reads it (15-minute precision inside 30-minute intervals); `breakGroups` retires. View exposes the plan; UI shows it; render scales walking by game speed and keeps break-room spots sticky.

**Tech Stack:** vanilla ES modules, Canvas 2D, `node --test`, jsdom, Python Playwright browser check.

**Spec:** `docs/superpowers/specs/2026-11-26-v1.6-breaks-design.md` · approved copy `docs/superpowers/specs/2026-11-26-v1.6-copy.md`

## Global Constraints

- Windows (minutes from shift start; 15-minute grid): am 15 min starts in [60,180−15]; lunch 60 min starts in [180, 330−60]; pm 15 min starts in [shift length−180, shift length−60−15]. Same for early, late and weekend shifts. Shift length 540; work 450.
- Skill `planning`: ranges agent [0,3], lead [3,8], qa [1,4], one decimal; derived deterministically from person id (no rng draw), for new and old people.
- Score per candidate slot = `q·load + (1−q)·noise`, `q = lead.planning / 10`, lower is better; `load` = forecast calls of the person's client in the slot ÷ (rostered agents of that client still working in the slot); `noise` uniform [0,1) from a day-seeded rng separate from the game rng (game rng draw order for calls must not change because of breaks).
- Lead away (not on shift at day start: off, sick, leave, absent, weekend) → q = 0, `by: 'auto'`; event `breaks-auto` on weekdays only.
- Weekday golden fixture is regenerated intentionally once (Task 3) with a ledger ruling; every other fixture change must be justified.
- Korean strings verbatim from approved copy; role tag uses existing `role.agent|lead|qa`.
- Autoplay: all existing checks pass; new check: same seed, lead planning 8 vs 1 → lead 8 has fewer abandoned calls and ≥ SL on ≥ 8/10 seeds. If any existing check fails, stop and report (do not retune without user).
- Implementers do not commit.

## Review Focus

1. Person whose shift starts at 12:00 (late) → windows relative to 12:00; pm ends ≥ 60 min before 21:00 (Task 2 test).
2. 15-minute break inside a 30-minute interval → work share 0.5 that interval only, total worked minutes 450 per full day (Task 2 test).
3. Lead sick on a weekday → all breaks `by: 'auto'`, one `breaks-auto` event that day, none on weekends (Task 3 test).
4. Save from v1.5 (no `state.breaks`, people without `planning`) → loads, plan made at next day start, current day falls back to a plan built on load (Task 3 test).
5. Role tag + "…" bubble + 💬/✉️ marker stacked without overlap for a row-1 person (Task 4 test).
