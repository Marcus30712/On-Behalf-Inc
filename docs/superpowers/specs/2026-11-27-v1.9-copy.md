# v1.9 문구 초안: 휴식표 직접 조정 (승인 필요)

자리표시:
- `{time}`: 시각(예: 10:30)
- `{calls}`, `{n}`: 정수
- `{name}`: 사람 이름

## 탭 (ui/text.js `tabs.breaks`)

| 키 | 문구 |
|---|---|
| name | 휴식표 |
| tip | 오늘 휴식 시간을 보고 바쁜 시간을 피해 옮겨요 |

## 휴식표 화면 (`breaks`)

| 키 | 문구 |
|---|---|
| title | 휴식표 |
| help | 오늘 휴식을 15분씩 앞당기거나 미룰 수 있어요. 바쁜 시간에 쉬는 사람이 몰리지 않게 해 주세요. |
| byLead | {name} 팀장이 짠 휴식표예요. |
| byAuto | 팀장이 없어 휴식이 무작위로 정해졌어요. |
| am | 오전 휴식 |
| lunch | 점심 |
| pm | 오후 휴식 |
| earlier | 15분 앞당기기 |
| later | 15분 미루기 |
| edited | 직접 조정 |
| slot | {time} · 예상 콜 {calls}건 · 쉬는 사람 {n}명 |
| busy | 바쁜 시간에 {n}명이 쉬어요 |
| legend | 막대는 30분마다 예상 콜이에요. 빨간 칸은 바쁜 시간에 쉬는 사람이 많은 곳이에요. |
| none | 오늘은 근무하는 사람이 없어요. |

## 거절 알림 (`refuse`)

| 키 | 문구 |
|---|---|
| not-working | 오늘 근무하지 않는 사람이에요. |
| bad-break | 휴식은 15분 단위로만 옮길 수 있어요. |
| break-started | 이미 시작했거나 지난 휴식은 옮길 수 없어요. |
| break-window | 그 시간으로는 옮길 수 없어요. 정해진 휴식 시간 범위를 벗어나요. |
