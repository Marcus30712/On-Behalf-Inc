# On Behalf Inc v1.5 — 그림 개편 설계 (짧은 설계)

- 날짜: 2026-11-25
- 상태: 추천안(참고만 하고 코드로 새로 그리기)으로 진행 승인(2026-11-25). 견본 화면은 사용자 확인 대기.
- 참고 자료: 사용자가 Gemini로 만든 이미지 6장(캐릭터 방향·동작, 사무실 소품, 사무실 전경). **이미지 자체는 저장소에 넣지 않는다.** 색감·옷차림·소품 종류·배치 아이디어만 참고한다.

## 왜

지금 상담사는 16×16이라 얼굴과 헤드셋이 잘 안 보이고 모두 비슷해 보인다. 사무실도 책상·의자·소파 정도라 컨택센터 느낌이 약하다. 사용자가 원하는 그림 방향(헤드셋 쓴 상담사, 다양한 사람들, 탕비실·화이트보드가 있는 사무실)에 맞춘다.

## 목표

1. **상담사 16×24:** 헤드셋, 깃, 벨트, 신발이 보이는 비율. 머리 모양(짧은 머리, 긴 머리, 곱슬, 묶은 머리), 안경 여부, 피부색 4단계 이상, 셔츠·바지 색을 사람마다 정해진 값(지금처럼 id 해시)으로 조합한다. 서기·걷기 두 장·앉기·뒷모습 앉기를 모두 새로 그린다.
2. **김미소(선배 매니저)와 팀장·QA**도 같은 비율로 다시 그린다. 생김새의 특징(밤색 단발, 둥근 안경, 겨자색 가디건)은 유지한다.
3. **새 소품(위에서 내려다본 지금 시점):** 정수기, 탕비실 카운터(커피 머신·전자레인지), 화이트보드, 게시판, 벽시계, 칸막이, 휴지통, 화분 2~3종. 벽에 거는 것은 벽 줄에, 바닥 소품은 지금 지나갈 수 없는 칸에만 둔다.
4. **지도와 경로는 그대로:** 칸 크기 16px, 지도 20×12, 지나갈 수 있는 칸, 좌석 위치를 바꾸지 않는다. 상담사는 한 칸보다 8px 위로 솟아 보인다(위 칸과 겹쳐 그림, 아래쪽부터 그리기 순서 유지).
5. **색:** 지금 OFFICE 팔레트를 기본으로 하고, 참고 이미지에서 가져온 파랑·초록·보라·흰 셔츠와 다양한 피부·머리색을 더한다.

## 하지 않는 것

새 기능·문구(소품에 이름표나 툴팁 없음), 지도 크기·좌석 수 변경, 애니메이션 프레임 추가(서기/걷기/앉기 외), 이미지 파일 불러오기 방식 도입.

## 접근

| 안 | 내용 | 판단 |
|---|---|---|
| **A (선택)** | 지금처럼 글자 격자로 코드 안에 그림 | 테스트·브라우저 점검이 그대로 돌아가고 파일 불러오기 실패가 없음 |
| B | PNG 스프라이트 시트로 바꿈 | 불러오기·캐시·테스트 구조를 바꿔야 함 |

## 성공의 증거

- 스프라이트 데이터 테스트(모든 줄 길이·팔레트 문자 유효), 사람마다 조합이 결정적.
- 평일 골든 파일과 시뮬레이션은 그대로(그림만 바뀜). 자동 플레이 결과 그대로.
- 브라우저 점검 통과, 견본과 같은 분위기의 스크린샷(평소·주말·채널·확장 2단계).
- 상담사가 위 칸과 겹칠 때 책상·의자 그리기 순서가 맞음(머리가 책상 뒤로 숨지 않음).
