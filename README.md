# On Behalf Inc

도트 그래픽의 2D 사무실에서 BPO 고객센터를 운영하는 시뮬레이션 게임입니다. 누구나 고객센터를 직접 꾸려 볼 수 있도록 만듭니다.

상담사, 팀장, QA는 저마다 특성과 기술을 가지고 있어요. 지치고, 아프고, 휴가를 가기도 합니다. 플레이어는 근무표와 업무 배치, 연구로 이들을 돌보고, 고객사의 서비스 레벨을 지켜 내야 합니다. 무대는 지구를 본뜬 가상의 행성입니다. 나라마다 다른 달력과 휴일이 직원의 결근과 고객의 콜 양을 함께 흔듭니다.

- 상태: 첫 플레이 버전(MVP)
- 설계 문서: [`docs/superpowers/specs/2026-11-24-on-behalf-inc-design.md`](docs/superpowers/specs/2026-11-24-on-behalf-inc-design.md)

## 플레이하기

플레이 주소: (배포 후 추가)

PC 브라우저(가로 1280 이상 권장, 1024에서도 플레이 가능)에서 열어 주세요. 처음 열면 새 게임을 고르고, 저장된 게임이 있으면 이어하기를 고를 수 있어요.

### 조작법

| 조작 | 하는 일 |
| --- | --- |
| 스페이스 | 멈춤 · 다시 시작 |
| 1 · 2 · 3 | 1배속 · 2배속 · 3배속 |
| 위쪽 막대의 ⏸ ▶ 버튼 | 속도 바꾸기 |
| 사무실의 사람 클릭 | 그 사람의 카드 열기(사람 탭) |
| 아래 탭(사람, 근무표, 업무 배치, 연구, 채용, 고객사, 달력) | 패널 열기 · 같은 탭을 다시 누르면 닫기 |
| 오른쪽 알림 클릭 | 알림 펼치기 · 선택지가 있으면 답 고르기 |

- 1배속에서 평일 영업 시간(09:00~21:00)은 실제 1초에 게임 6분이 흘러요. 영업 시간 밖과 주말은 빨리 지나가요.
- 선택지가 있는 새 알림이 오면 게임이 저절로 멈춰요.
- 하루가 끝날 때마다 브라우저(localStorage)에 자동 저장돼요. 서버로 보내는 것은 없어요.

### 로컬에서 실행하기

ES 모듈을 쓰기 때문에 파일을 바로 열면 동작하지 않아요. 저장소 폴더에서 정적 서버를 띄운 뒤 `http://localhost:8000`을 열어 주세요.

```
python3 -m http.server 8000
```

- 테스트: `npm test` (Node 22 이상)
- 브라우저 검사: `python3 tools/browser_check.py` (Python 3, Playwright, `/usr/bin/google-chrome` 필요). 스크린샷은 `tools/out/`에 남아요.
