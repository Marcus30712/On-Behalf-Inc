# v2.0 사무실 다듬기: 판단 기록

- 설계: `../specs/2026-11-27-v2.0-office-polish-design.md`(짧은 설계로, 계획 역할도 함께 한다)

| 판단 | 이유 | 틀렸을 때 비용 |
|---|---|---|
| 탕비 조리대를 (12–13, 10)으로 옮기고 새 타일 `N`을 만들었다. 정수기는 오른쪽 위에 그대로 둔다 | 조리대는 32×16이라 위 칸을 가리지 않는다. 정수기는 32픽셀 높이라 옮기려면 칸을 더 막아야 한다 | 걸을 수 있는 칸 두 개가 줄었다(지도 고정값을 일부러 바꿈) |
| 회색 머리는 나왔을 때 2분의 1 확률로만 유지한다 | 회색이 아닌 사람의 모습은 그대로다. 가중치 방식은 작은 구간에서 결과가 들쭉날쭉했다 | 회색이었던 사람 일부의 머리, 바지, 안경이 바뀐다 |
| 걷는 빠르기 상한은 초당 72칸(문을 연 시간 3배속 빠르기). 일시정지 중에는 걷지 않는다 | 문을 연 시간은 모든 배속에서 그대로이고, 밤에는 10칸이 약 9프레임에 걸쳐 보인다 | 밤에는 걷는 동안 게임 시간이 더 흐른다(약 17게임분). 처음 화면처럼 일시정지 중에 들어온 사람은 재생할 때까지 문 앞에 서 있다 |
| v1.6 테스트 "닫은 시간에도 3게임분 이내"는 문을 연 시간만 확인하도록 바꿨다 | 상한과 충돌한다. 설계에서 정한 변경이다 | 없음 |

참고: 미리보기 화면(`render/preview.html`)의 2단계 장면은 a0–a17이라는 임시 id를 써서 회색이 2명 보인다. 실제 게임의 처음 직원(p0–p9) 중 회색은 0명이다.

확인: npm test 546/546, autoplay 23/23(숫자 변화 없음), browser_check 통과, 스크린숏 확인.

## 최종 검토

중대한 지적과 중요한 지적은 없었다.

| 판단 | 이유 | 틀렸을 때 비용 |
|---|---|---|
| 일시정지 중에는 모든 걷기가 멈춘다. 채용하거나 업무를 바꿔도 재생할 때 움직인다 | 일시정지는 화면 전체가 멈추는 것으로 본다(이전에는 일시정지 중에도 천천히 걸었다) | 일시정지 중에 바꾼 내용이 화면에 바로 움직임으로 나타나지 않는다 |

다음 버전으로 미룬 것:
